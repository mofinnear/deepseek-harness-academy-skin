## 任务 1：白天通透版背景 · `academy-panorama-day.jpg`

**规格**：2560×1600（16:10），JPG，文件 ≤ 900 KB。

**生图提示词**（附图依次为 `assets/academy-panorama.jpg`、`docs/reference/效果图.webp`、`docs/reference/书桌参考.jpg`）：

```
以附图1为构图基础，重新绘制这张书院图书馆背景：建筑、书架、拱形大窗、楼梯、地板图案、天球仪和书桌等物件的位置和透视与附图1保持一致，只把时间和光线改成晴朗的上午，达到附图2、附图3那种明亮通透的感觉。横向 16:10，2560×1600 像素。

【光线——最重要】
- 晴朗的上午：中间高大的拱形窗户外是明亮的蓝天和白云，远处城堡被阳光照亮。
- 阳光从窗户斜照进来，形成柔和的光柱（体积光），空气中漂浮细小的光点和微尘。
- 大理石地板、书桌桌面、黄铜装饰上有明亮的阳光反射和倒影。
- 暗部是浅蓝紫色的柔和阴影，不是深蓝或黑色；整体明亮、干净、通透，像附图3。
- 保留蓝金配色：深蓝书脊、蓝色挂旗、金色装饰仍在，但蓝色更明亮清爽，金色在阳光下闪亮。
- 不要黄昏、夜晚、紫粉色晚霞、烛光主导的暖色；不要整体发灰、发白或蒙雾。

【构图要求——为界面留空】
- 画面中间约 55% 宽度的区域（会被对话框盖住）细节少、对比低、明亮平静。
- 画面右侧约 27% 区域（会站着角色）保持中等细节、偏冷的浅蓝色调，让角色更突出。
- 画面左侧约 22% 区域（会被深蓝侧栏盖住大半）可以保留书架细节。

【不要】
- 人物、文字、界面元素、水印、边框。
- 风格：日系二次元手游背景插画，与附图1一致。
```

**验收**：
1. 与 `assets/academy-panorama.jpg` 叠在一起（50% 透明度）对比，拱窗、书架、楼梯的位置大致重合。
2. 窗外是蓝天白云，没有晚霞；地板有阳光反光。
3. 用 Python 粗测亮度：整图平均亮度（0–255）应明显高于原图，暗部（第 10 百分位）不低于 40。

## 任务 2：白天光照的书桌 · `desk-v5.png`

**规格**：1200×1800，PNG，**真透明背景**（做不出透明就用纯品红 #FF00FF 平涂，交付前抠成透明）。
**构图必须与 `assets/ui/desk-v4-original.png` 逐像素一致**：这张书桌的前 1312 行与角色立绘逐像素对齐（桌面后沿在 y≈1142），一旦移动或缩放就会对不上角色的手臂。

**生图提示词**（附图依次为 `assets/ui/desk-v4-original.png`、`docs/reference/书桌参考.jpg`）：

```
以附图1为底图重新绘制这张书桌，构图、物件、位置、大小、透视全部与附图1完全一致（逐像素对齐，不要移动、缩放、增删任何东西），只改变颜色、明暗和光照，达到附图2里书桌那种「清亮」的质感。画布 1200×1800 像素，透明背景 PNG，桌子以外保持完全透明。

【颜色与光照】
- 光源：晴朗白天的阳光从画面右上方的窗户照进来，暖白色，桌面和黄铜件上有清晰明亮的阳光反光；阴影偏淡蓝紫。
- 木头：中等亮度的暖棕胡桃木（不是接近黑色的深褐，也不是发灰发白的浅色），木纹清晰。
- 明暗对比要足：桌子正面雕花板的凹槽、桌底、物件背光面保持深色，不要被提亮成灰色；不要蒙一层白雾。
- 桌面像打过蜡一样光亮，有清晰的反光条带和倒影；黄铜包角、立柱尖顶、墨水瓶、花瓶、八芒星摆件是明亮的金色，有闪亮的高光点。
- 桌旗：饱和的宝蓝色丝绒，金线刺绣明亮，流苏亮金色。
- 书本：深蓝皮面带光泽，烫金明亮，书页暖白色；百合洁白、淡黄花蕊、叶子清新的绿色。

【不要】
- 改变构图或物件；人物、手臂、文字；背景（地板、墙、窗户）。
- 整体发灰、发白、低对比；模糊。
- 风格：日系二次元手游插画，与附图1一致。
```

**验收**：
1. 尺寸 1200×1800，RGBA，四角像素完全透明。
2. 与 `desk-v4-original.png` 叠在一起，桌面后沿（y≈1142）、桌角立柱、书摞、花瓶的位置重合。可以这样粗测透明轮廓的重合度（IoU 应 ≥ 0.9）：
   ```bash
   python3 -c "
   from PIL import Image; import numpy as np
   a=np.array(Image.open('assets/ui/desk-v4-original.png').convert('RGBA'))[...,3]>128
   b=np.array(Image.open('<素材目录>/round5/desk-v5.png').convert('RGBA'))[...,3]>128
   print('IoU', round((a&b).sum()/(a|b).sum(),3))"
   ```
3. 桌子正面区域（x 100–1100，y 1300–1750）亮度目标，数值 0–255：平均 75–95、暗部（第 10 百分位）≤ 25、高光（第 90 百分位）≥ 190。原图分别是 49 / 14 / 105（太暗），程序提亮版是 109 / 71 / 172（发灰），参考图是 85 / 18 / 211。
