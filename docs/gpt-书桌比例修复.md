## 第三步（round8 之后）：角色在桌子后面，手和桌面互动

round8（`<素材目录>/round8/`，3014×2400）验收：书桌比例正确，桌旗圆环、花瓶都是圆的；但 GPT 没有照 desk-full 原样扩画，而是重画了书桌（底图区与 desk-full 平均差 19.85），所以以 round8 的书桌为准。用户反馈两个问题：

1. **角色像长在桌上**：整张立绘被叠在书桌上面，桌面后沿在角色身后，胸口以下的身体压在桌面中间，底部是一条平直横切线（开心那张最明显）。正确的遮挡关系应该是：桌面后沿挡住腰部以下的身体，只有搭在桌上的前臂和手画在桌面之上。

不画全身（用户确认）：书桌正面是封闭的雕花板，腿本来就被挡住；陪伴栏高度有限，放全身会让脸和表情变小；底部还有气泡和表情按钮压着。但要求 GPT 把身体在桌子后面画完整（坐在椅子上，延续到腰和大腿），让桌面后沿挡住的是一个完整的身体，而不是在桌面高度截断的半身像，这才是「长在桌上」的根本原因。

## 第四步（round9 之后）：去掉拼接痕，统一桌面物件

round9（3014×2400）验收：角色已经坐在桌子后面，默认表情的手压在书上，方向对了。书桌正面和桌面两侧四张完全一致，头的位置最多偏 2px，缩略图也有了。但四张都有拼接问题：

| 图 | 问题 |
| --- | --- |
| 默认 | 左侧书本处有一块方形补丁（竖直和水平的硬边），后面那本合着的书被它截断；墨水瓶被右侧头发盖住、发虚，羽毛笔浮在头发后面，和墨水瓶接不上 |
| 开心 | 羽毛笔顶部有一块颜色更亮的方块背景；衣服下沿半透明地压在桌面上（还是「长在桌上」），上方有一条水平拼接线 |
| 好奇 | 左侧两本翻开的书叠在一起、交界处糊成一片；羽毛笔顶部同样的方块；搭在桌上的前臂边缘发糊 |
| 眨眼 | 同好奇：两本书叠糊、羽毛笔方块、前臂边缘发糊 |
| 四张之间 | 桌面中段物件不一致（书的位置和开合、墨水瓶有无羽毛笔都不同），切换表情时物件会跳；头顶头发的细节每张略有不同（平均差 11–14），切换时会轻微闪动 |

原因：各部分是分块贴上去的，补丁用了矩形，没有沿物体轮廓羽化；桌面物件每张单独画，没有共用一套。
