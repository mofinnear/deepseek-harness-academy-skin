# 书桌比例修复（第八批）

> 2026-10-02。round7 合成图（第二次修订）里，书桌和桌上物件被横向压缩：桌旗上的圆环在 `desk-full.png` 里是正圆，到合成图里宽高比只剩约 0.55，八芒星、花瓶、书本也都变窄了。角色是原尺寸贴回去的，没有变形。`relight-v2/`、`relight-claude/` 都基于这批图，所以同样是压缩的。
>
> `desk-full.png`（1200×2200）是 GPT 早先单独画的书桌，比例、大小、颜色、物件位置都对（书本在角色左手下，墨水瓶、星芒摆件、花瓶在右侧），唯一的问题是左右两边和底部被画布截掉了。所以修复方法是：**让 GPT 以 desk-full 为底向外扩画，原有部分不动**；再由 Codex 等比合成角色、补阴影。
