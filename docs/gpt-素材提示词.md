# 星海书院皮肤 · GPT 生图提示词

使用方法：每次生成都**附上原效果图**作为参考，再粘贴对应提示词。一次只生成一张素材。

## 通用要求（已经写进每条提示词，这里方便你核对）

- 背景必须是**真正的透明 PNG**（alpha 通道），不要画灰白棋盘格。如果 GPT 做不出透明，就改成「纯品红色 #FF00FF 平涂背景，无渐变无阴影」，我来抠图（品红和蓝发、白围裙都不冲突，好抠）。
- 画面里**不要任何文字、Logo、UI 按钮、人物**（立绘和桌子那张除外）。
- 画风与参考图一致：日系二次元手游 UI，深蓝 + 香槟金配色，精致但线条干净。
- 边框类素材是「九宫格」：四角是花饰，四条边是可以拉伸的均匀线条，中间完全透明。这类图**边中间不要有任何花纹**，否则拉伸时会变形。
