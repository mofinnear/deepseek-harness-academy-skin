> 路径说明：`tools/…`、`assets/…`、`docs/…` 都相对于本项目根目录；`<素材目录>` 是存放生成图的目录，自行指定。

## 0. 规则

- **只产出图片，不改皮肤项目里的任何文件**（`brand-override/`、`tools/`、`logo.config.json` 都不要动）。图片交付后，由 Claude 负责接入和排版。
- 产出放到：`<素材目录>/expressions/`（没有这个目录就新建）。
- 所有图都必须是**真正的透明 PNG**（RGBA）。不要白底，也不要画出来的灰白棋盘格。

## 2. 必做：三张表情立绘（第二版：表情 + 姿势都要变化）

> 第一版只改了脸，三张都是「托腮 + 扶桌」，动作太单一。第二版要求**每个表情配一个不同的姿势**，
> 但头部位置、人物大小、桌面线必须和默认图对齐。界面切换表情时会淡入淡出，不会显得突兀。

### 对齐规则（自检脚本会检查）

| 项目 | 要求 | 默认立绘里的位置 |
| --- | --- | --- |
| 画布 | 1199×1312，真透明 RGBA | — |
| 头部 | 位置和大小不变，只允许轻微歪头（10° 以内） | 呆毛顶端 y≈6，头饰 y≈140–200，脸 x 260–720 / y 380–760 |
| 桌面线 | 前臂或手肘落在画布底部，y 1200–1300 一带要有约 500px 以上宽的手臂或身体 | 前臂横跨 x≈130–1130 |
| 底边 | 身体一直延伸到 y≥1270（最下面约 26px 会被桌子挡住） | 下沿 y≈1298 |
| 手 | 五指完整、结构正确，不要伸出画布左右边缘 | — |

### 通用提示词（每张都先贴这段，再接对应的「姿势 + 表情」）

附图 1 用默认立绘 `assets/academy-maid-pensive.png`，作为角色和构图基准；附图 2 用第一版对应的表情图，作为表情参考。

```
以附图1为角色、服装和构图基准，附图2为这一张的表情参考，画同一个角色的一个新姿势。
- 同一个角色、同一套服装（深蓝女仆裙、白色荷叶边、黑色领结和蓝宝石胸针、白色荷叶边头饰和蓝色蝴蝶结、带白羽毛的深蓝垂耳），画风、线条粗细、上色和光照与附图1完全一致。
- 画布 1199×1312 像素，真正的透明背景 PNG（不要棋盘格）；做不出透明就用纯品红 #FF00FF 平涂背景。
- 头部位置和大小与附图1一致：呆毛顶端贴近画布顶部，头饰、脸和两只垂耳基本在原位，只允许轻微歪头（10°以内）。
- 上半身被画布底边水平截断；她趴在一张桌子后面，前臂或手肘落在画布最下方（约 1200–1300 像素高度），那里会被桌子挡住一截。
- 手部五指完整、结构正确，手不要伸出画布左右边缘。
- 不要画桌子、文字或其他物体。
```

### 生成后对齐与自检

1. **对齐**：把新图以 50% 不透明度叠在默认立绘上，平移或等比缩放新图，让头饰、眼睛和两只垂耳与默认图重合，再导出 1199×1312。
2. **抠图**：如果用的是品红底，抠成透明，边缘柔和，不能有品红残边；白色头饰和衣领不能被抠掉。
3. **自检**（用 `pose` 模式，不再用只允许改脸的 `check`）：

   ```bash
   python3 "tools/expressions.py" pose "<素材目录>/expressions"
   ```

   出现 `FAIL` 时按提示修：「头部重合度低」→ 重新对齐头部；「人物顶端过低」→ 人物被缩小了，放大回原尺寸；「桌面线太窄」→ 手臂要落到画布底部。

4. 第一版的三张图请先改名备份（如 `expr-happy-v1.png`），不要直接覆盖。

## 3. 必做：四张表情缩略图（纯裁切，跑脚本）

三张立绘通过 `pose` 自检后，重新运行（会覆盖旧缩略图）：

```bash
python3 "tools/expressions.py" thumbs "<素材目录>/expressions"
```

脚本会用同一个固定裁切框（头饰顶部约在 8%，下巴约在 75%），在同一目录生成四张 256×256 缩略图：

- `expr-default-thumb.png`（来自默认立绘）
- `expr-happy-thumb.png`
- `expr-curious-thumb.png`
- `expr-wink-thumb.png`

**不要手动裁**，否则四张的大小和位置会对不齐。

## 4. 可选：便签 `memo.png`

右侧陪伴栏右上角的便签，目前是 CSS 画的纸片加楷体字。如果想要效果图里那种手绘质感，可以生成一张：

```

米黄色纸片，顺时针旋转约 6°，顶部中间一颗金色图钉，纸片自带柔和投影（投影不要超出画布）。
纸上手写三行文字：「一起」「把想法」「变成可能！」，右下角小字「— DeepSeek ✧」，深蓝灰色墨水，手写体。
```

- 生成后检查：四周透明、文字清楚、没有错字。
