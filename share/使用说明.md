# DeepSeek Harness「星海书院」皮肤 · 使用说明

给 DeepSeek Harness 桌面版（macOS）换上一套学院风外观：书院全景背景、深蓝星图侧栏、金边对话框和输入框，右侧还有一个会陪你聊天的角色（四个表情可切换，切换时会轻轻顶一下、闪出星光）。

> **非官方作品**：与 DeepSeek 官方无关。皮肤只改外观，聊天、模型、工作区等功能都还是应用原生的；**不修改应用本体和签名**，随时可以一键卸载。

效果见 `预览/` 文件夹：

| 文件 | 内容 |
| --- | --- |
| `01-新会话首页.png` | 整体效果 |
| `02-四个表情.png` | 默认 / 开心 / 好奇 / 眨眼 |
| `03-书院背景.png` 或 `.jpg` | 「只看背景」模式下的全景图 |
| `表情切换-整窗.gif`、`表情切换-特写.gif` | 切换表情的动图（同名 `.mp4` 画质更好） |

## 一、安装（推荐：双击脚本）

1. 先安装并**至少打开过一次** DeepSeek Harness 桌面版。
2. 把压缩包完整解压。
3. 双击 **`安装.command`**，会打开一个终端窗口自动完成安装。
4. 完全退出 DeepSeek Harness（菜单栏「退出」或 `Cmd + Q`，只关窗口不算），再重新打开。脚本最后也会问你要不要帮你重启，输入 `y` 回车即可。

**如果双击后提示「无法打开，因为无法验证开发者」**（从微信、网盘下载的文件常见）：

- 在访达里**按住 Control 点按**（或右键）`安装.command` → 选「打开」→ 再点「打开」；或者
- 打开「系统设置 → 隐私与安全性」，在下方找到这个文件，点「仍要打开」；或者
- 打开「终端」，输入 `bash `（bash 后面有一个空格），把 `安装.command` 拖进终端窗口，按回车。

安装脚本只改你自己用户目录里的两处：

- `~/.dsh/profiles/desktop/node_modules/@local/dsh-logo/`：皮肤插件文件；
- `~/.dsh/profiles/desktop/cordis.patch.yml`：在末尾追加一条插件加载项。

改动前会把这两处原来的内容备份到 `~/.dsh/academy-skin-backup/<日期时间>-安装前/`。

### 不想用脚本：手动安装

1. 在访达里按 `Cmd + Shift + G`，输入 `~/.dsh/profiles/desktop/` 回车（`.dsh` 是隐藏目录，这样才能进去）。先把里面的 `cordis.patch.yml` 复制一份备用。
2. 在这个目录里依次进入（没有就新建）`node_modules` → `@local` → `dsh-logo`，把压缩包里 `插件/dsh-logo/` 下的 `package.json`、`index.js` 和 `dist` 文件夹复制进去。
3. 用「文本编辑」打开 `cordis.patch.yml`，在文件**末尾**追加下面四行（缩进必须是空格，不能是 Tab），保存：

   ```yaml
   # Local logo override. Added by dsh-logo/tools/install.mjs; remove with --revert.
   - insert:
       - id: local-dsh-logo
         name: ./node_modules/@local/dsh-logo/index.js
   ```

4. 完全退出 DeepSeek Harness 再打开。

## 二、怎么用

| 操作 | 说明 |
| --- | --- |
| 切换皮肤 / 回到原版 | 左侧栏顶部的「星海书院 ▾」下拉菜单，可以在「星海书院」和「原版」之间切换，选择会记住 |
| 切换表情 | 点右下角四个表情缩略图（默认、开心、好奇、眨眼），气泡里的台词也会跟着变，选择会记住 |
| `Option + Shift + F` | 收起 / 展开右侧的角色陪伴栏，对话框会变宽 |
| `Option + Shift + B` | 「只看背景」：隐藏所有界面欣赏全景图，再按一次恢复 |
| 窗口很窄时 | 窗口宽度小于 1100 像素时，右侧陪伴栏会自动隐藏 |

开着皮肤时界面固定用浅色（即使系统是深色模式），切回「原版」就恢复你原来的主题设置。

## 三、卸载

- **推荐**：双击 **`卸载.command`**（被拦截时的处理方法同上），然后完全退出 DeepSeek Harness 再打开。它会删除插件文件，并从 `cordis.patch.yml` 里去掉那条加载项，其他设置不动。卸载前同样会备份到 `~/.dsh/academy-skin-backup/<日期时间>-卸载前/`。
- **手动**：删掉 `~/.dsh/profiles/desktop/node_modules/@local/dsh-logo/` 文件夹，再把 `cordis.patch.yml` 末尾追加的那四行删掉，然后重启应用。
- **只是暂时不想看**：不用卸载，在左侧栏顶部的下拉菜单里选「原版」就行。

## 四、常见问题

- **装完界面没变化**：插件只在应用启动时加载。请确认是完全退出（`Cmd + Q`）再打开，而不是只关了窗口。
- **提示找不到配置目录**：说明还没打开过 DeepSeek Harness，或者装的不是桌面版。先打开一次应用再安装。
- **应用更新后界面错乱**：皮肤基于 2026 年 9–10 月的 DeepSeek Harness 桌面版制作，应用大改版后部分样式可能对不上。先在下拉菜单切回「原版」，或直接卸载；等皮肤更新后再装。
- **想恢复安装前的状态**：备份在 `~/.dsh/academy-skin-backup/` 里，把里面的 `cordis.patch.yml` 复制回 `~/.dsh/profiles/desktop/` 即可。
