# DeepSeek Harness「星海书院」皮肤 · 使用说明

给 DeepSeek Harness 桌面版（macOS）换上一套学院风外观：书院全景背景、深蓝星图侧栏、金边对话框和输入框，右侧还有一个会陪你聊天的角色（四个表情可切换，切换时会轻轻顶一下、闪出星光）。

> **非官方作品**：与 DeepSeek 官方无关。皮肤只改外观，聊天、模型、工作区等功能都还是应用原生的；**不修改应用本体和签名**，随时可以一键卸载。

效果见 `预览/` 文件夹：

| 文件 | 内容 |
| --- | --- |
| `01-新会话首页.png` | 整体效果 |
| `02-四个表情.png` | 默认 / 开心 / 好奇 / 眨眼 |
| `03-书院背景.jpg` | 「只看背景」模式下的全景图 |
| `表情切换-整窗.gif`、`表情切换-特写.gif` | 切换表情的动图（同名 `.mp4` 画质更好） |

## ⚠️ 安装前必读

1. **先备份。** 安装会改动 `~/.dsh/profiles/desktop/` 里的两处（插件目录和 `cordis.patch.yml`）。不管用哪种方式安装，都要先把它们备份一份（安装脚本和下面「给 AI 助手的安装步骤」都会自动备份到 `~/.dsh/academy-skin-backup/`；手动安装请自己先复制一份）。
2. **`Option + Shift + B` 会把整个界面藏起来**，只剩背景图（用来欣赏全景）。如果误按了、界面突然全不见了，**再按一次 `Option + Shift + B`** 就恢复。
3. **`Option + Shift + F` 会收起右侧的角色陪伴栏**，再按一次展开。
4. 装完要**完全退出**（`Cmd + Q`）DeepSeek Harness 再打开才生效，只关窗口不行。

## 一、最简单：交给 DeepSeek Harness 自己装

1. 把压缩包完整解压。
2. 打开 DeepSeek Harness，在输入框左下角把权限从「工作区内修改」切到 **「完全权限」**（安装要写入工作区以外的 `~/.dsh` 目录，默认权限写不进去）。
3. 把这份 `使用说明.md` 拖进对话框（或用 `@` 引用它），发一句：**「请按这份说明里『给 AI 助手的安装步骤』安装星海书院皮肤，先备份。」**
4. 它装好后，按 `Cmd + Q` 完全退出 DeepSeek Harness，再重新打开。
5. 记得把权限切回「工作区内修改」。

## 二、自己装：双击脚本

1. 先安装并**至少打开过一次** DeepSeek Harness 桌面版。
2. 把压缩包完整解压。
3. 双击 **`安装.command`**，会打开一个终端窗口自动完成安装（**脚本会先自动备份**到 `~/.dsh/academy-skin-backup/<日期时间>-安装前/`）。
4. 完全退出 DeepSeek Harness（`Cmd + Q`），再重新打开。脚本最后也会问你要不要帮你重启，输入 `y` 回车即可。

**如果双击后提示「无法打开，因为无法验证开发者」**（从微信、网盘下载的文件常见）：

- 在访达里**按住 Control 点按**（或右键）`安装.command` → 选「打开」→ 再点「打开」；或者
- 打开「系统设置 → 隐私与安全性」，在下方找到这个文件，点「仍要打开」；或者
- 打开「终端」，输入 `bash `（bash 后面有一个空格），把 `安装.command` 拖进终端窗口，按回车。

### 不想用脚本：手动安装

1. 在访达里按 `Cmd + Shift + G`，输入 `~/.dsh/profiles/desktop/` 回车（`.dsh` 是隐藏目录，这样才能进去）。
2. **先备份**：把里面的 `cordis.patch.yml` 复制一份到别处；如果 `node_modules/@local/dsh-logo/` 已经存在，也整个复制一份。
3. 在这个目录里依次进入（没有就新建）`node_modules` → `@local` → `dsh-logo`，把压缩包里 `插件/dsh-logo/` 下的 `package.json`、`index.js` 和 `dist` 文件夹复制进去。
4. 用「文本编辑」打开 `cordis.patch.yml`，在文件**末尾**追加下面四行（缩进必须是空格，不能是 Tab），保存：

   ```yaml
   # Local logo override. Added by dsh-logo/tools/install.mjs; remove with --revert.
   - insert:
       - id: local-dsh-logo
         name: ./node_modules/@local/dsh-logo/index.js
   ```

5. 完全退出 DeepSeek Harness 再打开。

## 三、怎么用

| 操作 | 说明 |
| --- | --- |
| 切换皮肤 / 回到原版 | 左侧栏顶部的「星海书院 ▾」下拉菜单，在「星海书院」和「原版」之间切换，选择会记住 |
| 切换表情 | 点右下角四个表情缩略图（默认、开心、好奇、眨眼），气泡里的台词也会跟着变，选择会记住 |
| `Option + Shift + B` | **隐藏全部界面**，只看背景全景图；再按一次恢复 |
| `Option + Shift + F` | 收起 / 展开右侧的角色陪伴栏，对话框会变宽 |
| 窗口很窄时 | 窗口宽度小于 1100 像素时，右侧陪伴栏会自动隐藏 |

开着皮肤时界面固定用浅色（即使系统是深色模式），切回「原版」就恢复你原来的主题设置。

## 四、卸载

- **推荐**：双击 **`卸载.command`**（被拦截时的处理方法同上），然后完全退出 DeepSeek Harness 再打开。它会删除插件文件，并从 `cordis.patch.yml` 里去掉那条加载项，其他设置不动。卸载前同样会备份到 `~/.dsh/academy-skin-backup/<日期时间>-卸载前/`。
- **让 DeepSeek Harness 卸载**：切到「完全权限」，发一句「请按使用说明里的步骤卸载星海书院皮肤」。
- **手动**：删掉 `~/.dsh/profiles/desktop/node_modules/@local/dsh-logo/` 文件夹，再把 `cordis.patch.yml` 末尾追加的那四行删掉，然后重启应用。
- **只是暂时不想看**：不用卸载，在左侧栏顶部的下拉菜单里选「原版」就行。

## 五、常见问题

- **界面突然全不见了，只剩一张背景图**：误按了 `Option + Shift + B`，再按一次就恢复。
- **右边的角色不见了**：按了 `Option + Shift + F`（再按一次），或者窗口太窄（小于 1100 像素会自动隐藏，拉宽窗口即可）。
- **装完界面没变化**：插件只在应用启动时加载。请确认是完全退出（`Cmd + Q`）再打开，而不是只关了窗口。
- **让 DeepSeek Harness 安装时提示没有权限**：把输入框左下角的权限切到「完全权限」再让它继续；装完切回来。
- **提示找不到配置目录**：说明还没打开过 DeepSeek Harness，或者装的不是桌面版。先打开一次应用再安装。
- **应用更新后界面错乱**：皮肤基于 2026 年 9–10 月的 DeepSeek Harness 桌面版制作，应用大改版后部分样式可能对不上。先在下拉菜单切回「原版」，或直接卸载；等皮肤更新后再装。
- **想恢复安装前的状态**：备份在 `~/.dsh/academy-skin-backup/` 里。把对应时间的 `cordis.patch.yml` 复制回 `~/.dsh/profiles/desktop/`；如果备份里有 `dsh-logo` 文件夹，也复制回 `~/.dsh/profiles/desktop/node_modules/@local/`（没有就删掉那里的 `dsh-logo`），再重启应用。

## 六、给 AI 助手的安装步骤

> 这一节写给替用户安装的 AI 助手（例如 DeepSeek Harness）。请按顺序执行，每一步检查结果；任何一步失败就停下来，把错误原样告诉用户，不要尝试绕过权限或沙箱。

**约定**：`PKG` = 这份说明所在的文件夹（里面有 `安装.command`、`卸载.command` 和 `插件/dsh-logo/dist/client.js`）。`P` = `~/.dsh/profiles/desktop`。

1. **找到安装包、确认环境**
   - 确认 `"$PKG/插件/dsh-logo/dist/client.js"` 存在。如果用户只给了这份说明、你不知道它在哪个文件夹，可以在 `~/Downloads`、`~/Desktop` 下找 `星海书院皮肤-v*/安装.command`；找不到就请用户告诉你解压后的文件夹位置。
   - 确认 `~/.dsh/profiles/desktop` 存在（不存在说明用户没打开过 DeepSeek Harness 桌面版，停下来告诉用户）。
2. **权限**：下面要写入 `~/.dsh/`（工作区以外）。如果写入被拒绝，停下来请用户把输入框左下角的权限切到「完全权限」，然后再继续。
3. **先备份（必须）**，并把备份路径告诉用户：

   ```bash
   P=~/.dsh/profiles/desktop
   B=~/.dsh/academy-skin-backup/$(date +%Y%m%d-%H%M%S)-安装前
   mkdir -p "$B"
   [ -f "$P/cordis.patch.yml" ] && cp "$P/cordis.patch.yml" "$B/"
   [ -d "$P/node_modules/@local/dsh-logo" ] && cp -R "$P/node_modules/@local/dsh-logo" "$B/dsh-logo"
   ls -la "$B"
   ```

4. **安装**（脚本会再备份一次；重复运行不会重复添加加载项；`< /dev/null` 让它跳过结尾的交互提问）：

   ```bash
   bash "$PKG/安装.command" < /dev/null
   ```

5. **检查**（三项都要通过）：

   ```bash
   P=~/.dsh/profiles/desktop
   ls -la "$P/node_modules/@local/dsh-logo" "$P/node_modules/@local/dsh-logo/dist"
   grep -c "id: local-dsh-logo" "$P/cordis.patch.yml"            # 应该是 1
   cmp "$PKG/插件/dsh-logo/dist/client.js" "$P/node_modules/@local/dsh-logo/dist/client.js" && echo 一致
   ```

6. **不要退出或重启 DeepSeek Harness**（你自己就运行在里面）。请用户自己按 `Cmd + Q` 完全退出再打开。
7. **装完把这些信息告诉用户**：
   - 备份在哪里（第 3 步的路径），以及怎么恢复（见「五、常见问题」最后一条）。
   - 需要 `Cmd + Q` 完全退出再打开才生效。
   - **`Option + Shift + B` 会隐藏全部界面、只剩背景，再按一次恢复**；`Option + Shift + F` 收起 / 展开右侧角色栏。
   - 左侧栏顶部「星海书院 ▾」下拉菜单可以切回「原版」；右下角四个缩略图切换表情。
   - 卸载：双击 `卸载.command`，或让你按下面的步骤卸载。
   - 可以把权限切回「工作区内修改」了。

**卸载**（同样需要「完全权限」，同样不要重启应用）：

```bash
bash "$PKG/卸载.command" < /dev/null
grep -c "id: local-dsh-logo" ~/.dsh/profiles/desktop/cordis.patch.yml   # 应该是 0
```

脚本会先备份到 `~/.dsh/academy-skin-backup/<时间>-卸载前/`，删除插件目录，并只去掉 `cordis.patch.yml` 里那四行。完成后请用户 `Cmd + Q` 重开。
