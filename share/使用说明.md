# DeepSeek Harness「星海书院」皮肤 · 使用说明

给 DeepSeek Harness 桌面版换上一套学院风外观：书院全景背景、深蓝星图侧栏、金边对话框和输入框，右侧还有一个会陪你聊天的角色（四个表情可切换，切换时会轻轻顶一下、闪出星光）。支持 **macOS** 和 **Windows**。

> **非官方作品**：与 DeepSeek 官方无关。皮肤只改外观，聊天、模型、工作区等功能都还是应用原生的；**不修改应用本体和签名**，随时可以一键卸载。
>
> **Windows 说明**：皮肤在 macOS 上制作和测试；Windows 版的安装脚本和界面适配是按应用的 Windows 代码写的，**还没有在 Windows 实机上验证过**。遇到问题请反馈，或者直接在下拉菜单切回「原版」/ 卸载。

效果见 `preview/` 文件夹：

| 文件 | 内容 |
| --- | --- |
| `01-新会话首页.png` | 整体效果 |
| `02-四个表情.png` | 默认 / 开心 / 好奇 / 眨眼 |
| `03-书院背景.jpg` | 「只看背景」模式下的全景图 |
| `表情切换-整窗.gif`、`表情切换-特写.gif` | 切换表情的动图（同名 `.mp4` 画质更好） |

## ⚠️ 安装前必读

1. **先备份。** 安装会改动 DeepSeek Harness 配置目录里的两处（插件目录和 `cordis.patch.yml`）。配置目录在：
   - macOS：`~/.dsh/profiles/desktop/`
   - Windows：`%USERPROFILE%\.dsh\profiles\desktop\`（即 `C:\Users\你的用户名\.dsh\profiles\desktop\`）

   安装脚本和下面「给 AI 助手的安装步骤」都会先自动备份到同一个 `.dsh` 下的 `academy-skin-backup` 文件夹；手动安装请自己先复制一份。
2. **`Option + Shift + B`（Windows 是 `Alt + Shift + B`）会把整个界面藏起来**，只剩背景图（用来欣赏全景）。如果误按了、界面突然全不见了，**再按一次同样的键**就恢复。
3. **`Option + Shift + F`（Windows 是 `Alt + Shift + F`）会收起右侧的角色陪伴栏**，再按一次展开。
4. 装完要**完全退出** DeepSeek Harness 再打开才生效：macOS 按 `Cmd + Q`（只关窗口不行）；Windows 关掉所有窗口，如果任务栏右下角托盘里还有它的图标，右键退出。

## 一、最简单：交给 DeepSeek Harness 自己装

1. 把压缩包完整解压。
2. 打开 DeepSeek Harness，在输入框左下角把权限从「工作区内修改」切到 **「完全权限」**（安装要写入工作区以外的 `.dsh` 目录，默认权限写不进去）。
3. 把这份 `使用说明.md` 拖进对话框（或用 `@` 引用它），发一句：**「请按这份说明里『给 AI 助手的安装步骤』安装星海书院皮肤，先备份。」**
4. 它装好后，完全退出 DeepSeek Harness 再重新打开。
5. 记得把权限切回「工作区内修改」。

## 二、自己装：双击脚本

先安装并**至少打开过一次** DeepSeek Harness 桌面版，再把压缩包完整解压。脚本都会**先自动备份**，再安装；重复运行不会重复添加。

### macOS

1. 双击 **`安装.command`**，会打开一个终端窗口自动完成安装。
2. 按 `Cmd + Q` 完全退出 DeepSeek Harness，再重新打开（脚本最后也会问要不要帮你重启，输入 `y` 回车即可）。

如果提示「无法打开，因为无法验证开发者」（从微信、网盘下载的文件常见）：在访达里**按住 Control 点按**（或右键）`安装.command` → 选「打开」→ 再点「打开」；或者打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」；或者打开「终端」，输入 `bash `（后面有一个空格），把 `安装.command` 拖进去，按回车。

### Windows

1. 双击 **`安装-Windows.bat`**，会打开一个窗口自动完成安装，最后按任意键关闭。
2. 完全退出 DeepSeek Harness（关掉所有窗口，托盘里有图标的话右键退出），再重新打开。

如果弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。如果解压出来的文件名是乱码，用 7-Zip 或 Bandizip 重新解压（Windows 自带的解压在少数旧版本上不认中文文件名）。

### 不想用脚本：手动安装

1. 打开配置目录（macOS：在访达里按 `Cmd + Shift + G`，输入 `~/.dsh/profiles/desktop/`；Windows：在资源管理器地址栏输入 `%USERPROFILE%\.dsh\profiles\desktop` 回车）。
2. **先备份**：把里面的 `cordis.patch.yml` 复制一份到别处；如果 `node_modules/@local/dsh-logo/` 已经存在，也整个复制一份。
3. 在这个目录里依次进入（没有就新建）`node_modules` → `@local` → `dsh-logo`，把压缩包里 `plugin/dsh-logo/` 下的 `package.json`、`index.js` 和 `dist` 文件夹复制进去。
4. 用文本编辑器（「文本编辑」/ 记事本）打开 `cordis.patch.yml`，在文件**末尾**追加下面四行（缩进必须是空格，不能是 Tab），保存为 UTF-8：

   ```yaml
   # Local logo override. Added by dsh-logo/tools/install.mjs; remove with --revert.
   - insert:
       - id: local-dsh-logo
         name: ./node_modules/@local/dsh-logo/index.js
   ```

5. 完全退出 DeepSeek Harness 再打开。

## 三、怎么用

| 操作 | 说明 |
| --- | --- |
| 切换皮肤 / 回到原版 | 左侧栏顶部的「星海书院 ▾」下拉菜单，在「星海书院」和「原版」之间切换，选择会记住 |
| 切换表情 | 点右下角四个表情缩略图（默认、开心、好奇、眨眼），气泡里的台词也会跟着变，选择会记住 |
| `Option + Shift + B`（Windows：`Alt + Shift + B`） | **隐藏全部界面**，只看背景全景图；再按一次恢复 |
| `Option + Shift + F`（Windows：`Alt + Shift + F`） | 收起 / 展开右侧的角色陪伴栏，对话框会变宽 |
| 窗口很窄时 | 窗口宽度小于 1100 像素时，右侧陪伴栏会自动隐藏 |

开着皮肤时界面固定用浅色（即使系统是深色模式），切回「原版」就恢复你原来的主题设置。

## 四、卸载

- **推荐**：双击 **`卸载.command`**（macOS）或 **`卸载-Windows.bat`**（Windows），然后完全退出 DeepSeek Harness 再打开。它会删除插件文件，并从 `cordis.patch.yml` 里只去掉安装时加的那几行，其他设置不动。卸载前同样会备份到 `academy-skin-backup/<日期时间>-卸载前/`。
- **让 DeepSeek Harness 卸载**：切到「完全权限」，发一句「请按使用说明里的步骤卸载星海书院皮肤」。
- **手动**：删掉配置目录下的 `node_modules/@local/dsh-logo/` 文件夹，再把 `cordis.patch.yml` 末尾追加的那四行删掉，然后重启应用。
- **只是暂时不想看**：不用卸载，在左侧栏顶部的下拉菜单里选「原版」就行。

## 五、常见问题

- **界面突然全不见了，只剩一张背景图**：误按了 `Option + Shift + B`（Windows：`Alt + Shift + B`），再按一次就恢复。
- **右边的角色不见了**：按了 `Option + Shift + F`（Windows：`Alt + Shift + F`，再按一次），或者窗口太窄（小于 1100 像素会自动隐藏，拉宽窗口即可）。
- **装完界面没变化**：插件只在应用启动时加载。请确认是完全退出再打开（macOS 用 `Cmd + Q`；Windows 连托盘图标一起退出）。
- **让 DeepSeek Harness 安装时提示没有权限**：把输入框左下角的权限切到「完全权限」再让它继续；装完切回来。
- **提示找不到配置目录**：说明还没打开过 DeepSeek Harness，或者装的不是桌面版。先打开一次应用再安装。
- **Windows：按 `Alt + Shift` 切换了输入法**：`Alt + Shift` 也是 Windows 切换输入语言的默认快捷键。三个键一起按通常不会切换；如果会，可以在「设置 → 时间和语言 → 输入 → 高级键盘设置 → 输入语言热键」里改掉，或者不用这两个快捷键（它们只是可选功能）。
- **应用更新后界面错乱**：皮肤基于 2026 年 9–10 月的 DeepSeek Harness 桌面版制作，应用大改版后部分样式可能对不上。先在下拉菜单切回「原版」，或直接卸载；等皮肤更新后再装。
- **想恢复安装前的状态**：备份在 `.dsh/academy-skin-backup/` 里。把对应时间的 `cordis.patch.yml` 复制回配置目录；如果备份里有 `dsh-logo` 文件夹，也复制回配置目录的 `node_modules/@local/`（没有就删掉那里的 `dsh-logo`），再重启应用。

## 六、给 AI 助手的安装步骤

> 这一节写给替用户安装的 AI 助手（例如 DeepSeek Harness）。请按顺序执行，每一步检查结果；任何一步失败就停下来，把错误原样告诉用户，不要尝试绕过权限或沙箱。先判断系统：macOS 用 bash 命令，Windows 用 PowerShell 命令。**每个代码块都可以单独执行**（开头都会重新算一遍路径），不要省略开头那几行。

**约定**：`PKG` = 这份说明所在的文件夹（里面有 `安装.command`、`安装-Windows.bat`、`windows/` 和 `plugin/dsh-logo/dist/client.js`），执行前先把它设成实际路径。配置目录 `P` 按安装脚本相同的顺序确定：设置了 `DSH_PROFILE_DIR` 就用它；否则是 `DSH_HOME`（没设置时为用户目录下的 `.dsh`）下的 `profiles/desktop`。备份放在同一个 `.dsh` 下的 `academy-skin-backup`。

1. **找到安装包、确认环境**
   - 确认 `PKG/plugin/dsh-logo/dist/client.js` 存在。如果用户只给了这份说明、你不知道它在哪个文件夹，可以在用户的「下载」「桌面」下找 `星海书院皮肤-v*` 文件夹；找不到就请用户告诉你解压后的位置。
   - 用下面第 3 步开头的几行算出 `P`，确认它存在（不存在说明用户没打开过 DeepSeek Harness 桌面版，停下来告诉用户）。
2. **权限**：下面要写入 `.dsh`（工作区以外）。如果写入被拒绝，停下来请用户把输入框左下角的权限切到「完全权限」，然后再继续。
3. **先备份（必须）**，并把备份路径告诉用户：

   macOS：
   ```bash
   H="${DSH_HOME:-$HOME/.dsh}"; P="${DSH_PROFILE_DIR:-$H/profiles/desktop}"
   B="$H/academy-skin-backup/$(date +%Y%m%d-%H%M%S)-安装前"
   mkdir -p "$B" || exit 1
   if [ -f "$P/cordis.patch.yml" ]; then cp "$P/cordis.patch.yml" "$B/" || exit 1; fi
   if [ -d "$P/node_modules/@local/dsh-logo" ]; then cp -R "$P/node_modules/@local/dsh-logo" "$B/dsh-logo" || exit 1; fi
   ls -la "$B"
   ```

   Windows（PowerShell）：
   ```powershell
   $H = if ($env:DSH_HOME) { $env:DSH_HOME } else { Join-Path $env:USERPROFILE '.dsh' }
   $P = if ($env:DSH_PROFILE_DIR) { $env:DSH_PROFILE_DIR } else { Join-Path $H 'profiles\desktop' }
   $B = Join-Path $H ('academy-skin-backup\' + (Get-Date -Format 'yyyyMMdd-HHmmss') + '-安装前')
   $ErrorActionPreference = 'Stop'
   New-Item -ItemType Directory -Force $B | Out-Null
   if (Test-Path "$P\cordis.patch.yml") { Copy-Item "$P\cordis.patch.yml" $B }
   if (Test-Path "$P\node_modules\@local\dsh-logo") { Copy-Item "$P\node_modules\@local\dsh-logo" "$B\dsh-logo" -Recurse }
   Get-ChildItem $B
   ```

4. **安装**（脚本会再备份一次；重复运行不会重复添加加载项；如果配置里已有一条同名但指向别的路径的加载项，脚本会停下并说明，这时把原话告诉用户）：

   macOS（`< /dev/null` 让它跳过结尾的交互提问）：
   ```bash
   bash "$PKG/安装.command" < /dev/null
   ```

   Windows：
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "$PKG\windows\install.ps1"
   ```

5. **检查**（三项都要通过）：

   macOS：
   ```bash
   H="${DSH_HOME:-$HOME/.dsh}"; P="${DSH_PROFILE_DIR:-$H/profiles/desktop}"
   ls -la "$P/node_modules/@local/dsh-logo" "$P/node_modules/@local/dsh-logo/dist"
   grep -cE '^[[:space:]]*- id: local-dsh-logo[[:space:]]*$' "$P/cordis.patch.yml"   # 应该是 1
   cmp "$PKG/plugin/dsh-logo/dist/client.js" "$P/node_modules/@local/dsh-logo/dist/client.js" && echo 一致
   ```

   Windows：
   ```powershell
   $H = if ($env:DSH_HOME) { $env:DSH_HOME } else { Join-Path $env:USERPROFILE '.dsh' }
   $P = if ($env:DSH_PROFILE_DIR) { $env:DSH_PROFILE_DIR } else { Join-Path $H 'profiles\desktop' }
   Get-ChildItem "$P\node_modules\@local\dsh-logo" -Recurse
   (Select-String -Path "$P\cordis.patch.yml" -Pattern '^\s*- id: local-dsh-logo\s*$').Count   # 应该是 1
   (Get-FileHash "$PKG\plugin\dsh-logo\dist\client.js").Hash -eq (Get-FileHash "$P\node_modules\@local\dsh-logo\dist\client.js").Hash   # 应该是 True
   ```

6. **不要退出或重启 DeepSeek Harness**（你自己就运行在里面）。请用户自己完全退出再打开（macOS `Cmd + Q`；Windows 关掉所有窗口并从托盘退出）。
7. **装完把这些信息告诉用户**：
   - 备份在哪里（第 3 步的路径），以及怎么恢复（见「五、常见问题」最后一条）。
   - 需要完全退出再打开才生效。
   - **`Option + Shift + B`（Windows：`Alt + Shift + B`）会隐藏全部界面、只剩背景，再按一次恢复**；`Option/Alt + Shift + F` 收起 / 展开右侧角色栏。
   - 左侧栏顶部「星海书院 ▾」下拉菜单可以切回「原版」；右下角四个缩略图切换表情。
   - 卸载：双击 `卸载.command` / `卸载-Windows.bat`，或让你按下面的步骤卸载。
   - 可以把权限切回「工作区内修改」了。

**卸载**（同样需要「完全权限」，同样不要重启应用）：

macOS：
```bash
bash "$PKG/卸载.command" < /dev/null
H="${DSH_HOME:-$HOME/.dsh}"; P="${DSH_PROFILE_DIR:-$H/profiles/desktop}"
grep -cE '^[[:space:]]*- id: local-dsh-logo[[:space:]]*$' "$P/cordis.patch.yml"   # 应该是 0
```

Windows：
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$PKG\windows\uninstall.ps1"
$H = if ($env:DSH_HOME) { $env:DSH_HOME } else { Join-Path $env:USERPROFILE '.dsh' }
$P = if ($env:DSH_PROFILE_DIR) { $env:DSH_PROFILE_DIR } else { Join-Path $H 'profiles\desktop' }
(Select-String -Path "$P\cordis.patch.yml" -Pattern '^\s*- id: local-dsh-logo\s*$').Count   # 应该是 0
```

脚本会先备份到 `academy-skin-backup/<时间>-卸载前/`，确认插件目录确实是本皮肤（不是就停下、不删），先改配置文件（只去掉安装时加的那几行），成功后再删除插件目录。完成后请用户完全退出再打开。
